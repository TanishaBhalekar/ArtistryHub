# 🎨 ArtistryHub – Premium AI-Powered Workspace

ArtistryHub is a full-stack digital workspace built specifically for digital and traditional creators. It combines comprehensive portfolio presentation tools, an automated commission tracker management pipeline, and an array of locally managed creative styling modules into a unified desktop dashboard environment.

## 🚀 Key Architectural Features
- **Zero-Cost Local AI Engine**: Implements edge analytics modules running entirely via localized data processing scripts, eliminating reliance on expensive cloud model endpoints.
- **Masonry Visual Pipeline**: A Pinterest-style fluid portfolio showcase complete with an asynchronous media pipeline that optimizes file compression and asset generation.
- **Kanban Task Framework**: A specialized tracking solution that handles client orders from initial acceptance steps through final delivery phases.

## 🛠️ Technical Stack
- **Backend Core**: Flask, Flask-SQLAlchemy, Flask-Login
- **Data Engine**: SQLite / PostgreSQL
- **Image Intelligence Pipeline**: OpenCV, Pillow (PIL), Scikit-Learn (K-Means Clustering)
- **Frontend Design**: Responsive HTML5, Bootstrap 5, Glassmorphism Custom UI Styles

## 🎨 Local Processing Highlights
### Palette Lab
Instead of querying paid third-party platforms, the platform parses uploaded artwork pixels directly using **Scikit-Learn's K-Means clustering algorithm** to mathematically map, evaluate, and return the 5 dominant color profiles on an interactive user dashboard layout.
